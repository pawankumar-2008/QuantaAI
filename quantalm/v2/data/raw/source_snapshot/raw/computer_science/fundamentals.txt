A computer program is a set of instructions that tells a computer how to perform a task.
Programming languages allow humans to express these instructions in a structured form.
A variable is a named location used to store a value.
A function is a reusable block of code that performs a particular operation.
A loop repeats a block of instructions while a condition is satisfied.
A conditional statement selects an action based on whether a condition is true or false.

Java is an object-oriented programming language.
A class defines the structure and behavior of objects.
An object is an instance of a class.
Encapsulation combines data and methods while controlling access to internal state.
Inheritance allows a class to reuse or extend the behavior of another class.
Polymorphism allows the same interface to support different implementations.
An interface defines a contract that implementing classes must follow.
An exception represents an error or unusual condition during program execution.

A data structure organizes information so that it can be stored and accessed efficiently.
An array stores elements in indexed positions.
A linked list consists of nodes connected through references.
A stack follows the last in first out principle.
A queue follows the first in first out principle.
A tree organizes data into parent and child relationships.
A graph represents relationships between vertices connected by edges.
A hash table stores key and value pairs using a hashing function.

An algorithm is a sequence of steps used to solve a problem.
Linear search checks elements one by one.
Binary search repeatedly divides a sorted search range into smaller parts.
Binary search has logarithmic time complexity.
Sorting algorithms arrange data according to a chosen order.
Time complexity describes how an algorithm's running time grows with input size.
Space complexity describes how memory requirements grow with input size.

A database stores organized information.
A database management system provides tools to create, read, update, and delete data.
A relational database organizes information into tables.
A table contains rows and columns.
A primary key uniquely identifies a row.
A foreign key represents a relationship between tables.
SQL is a language used to work with relational databases.
Normalization organizes relational tables to reduce unnecessary duplication.
A database transaction groups operations into a logical unit of work.
Atomicity means a transaction completes entirely or does not take effect.
Consistency preserves database rules and constraints.
Isolation controls how concurrent transactions interact.
Durability means committed changes persist.

An operating system manages computer hardware and software resources.
A process is a program in execution.
A thread is a unit of execution within a process.
The scheduler allocates processor time to runnable tasks.
Virtual memory gives processes an abstraction of available memory.
Deadlock can occur when processes wait indefinitely for resources.
A file system organizes files and directories on storage devices.

A computer network connects devices so they can exchange information.
An IP address identifies a network interface within an IP network.
The Transmission Control Protocol provides reliable ordered byte delivery.
The User Datagram Protocol sends datagrams without guaranteeing delivery.
The Domain Name System maps domain names to network records.
HTTP is a protocol used to transfer web resources.
HTTPS protects HTTP communication using Transport Layer Security.

Mathematics provides tools for reasoning about quantities and relationships.
A set is a collection of distinct elements.
A function maps inputs to outputs according to a defined rule.
A probability measures the likelihood of an event.
A matrix is a rectangular arrangement of values.
Logic uses formal rules to evaluate statements and arguments.

A language model learns statistical patterns from sequences of tokens.
A tokenizer converts text into token identifiers.
An embedding maps a token identifier to a vector of numbers.
A neural network contains layers of parameterized computations.
A Transformer uses attention to process relationships between tokens.
Self-attention allows a token representation to incorporate information from other tokens.
A loss function measures how far a prediction is from its target.
Backpropagation computes gradients used to update model parameters.
Gradient descent adjusts parameters to reduce the training loss.
Training data is used to update model parameters.
Validation data helps estimate performance on unseen examples.
Overfitting occurs when a model learns training examples without generalizing well.
A language model trained from scratch begins with randomly initialized parameters.
The model predicts tokens based on patterns learned during training.
