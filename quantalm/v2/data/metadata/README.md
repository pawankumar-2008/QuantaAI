# Dataset Metadata

Registered local dataset metadata is stored in `registrations/`. The source
inventory in `source_candidates.json` records official source/license pages
reviewed for this workflow. No external files were downloaded as part of this
implementation.

Licensing is validated per document, not inherited automatically from a
dataset name or host. Unknown, NonCommercial, and NoDerivatives terms are
rejected. ShareAlike material requires explicit recorded review because the
release obligations may affect redistribution. A `license_verified` attestation
is a human claim and is not an automatic legal determination.
